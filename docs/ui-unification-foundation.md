# UI Unification Foundation

この文書は、UI統一作業で採用する基準を記録する。

## 優先順位

1. 保存データ互換性を壊さない
2. 計算ロジックを変えない
3. 共通UIを先に揃える
4. 個別画面の例外を減らす
5. 最後にPC / モバイルの崩れを整える

## 共通化するもの

- 色
- 文字サイズと行間
- 枠線
- 角丸
- 影
- 余白
- 入力欄
- セレクト
- ボタン
- カード
- タブ / 選択状態
- 補足文 / 警告 / エラーの役割

## 色の原則

- 通常テキスト: 濃いニュートラル
- 補足: muted
- ブランド / 選択状態: 落ち着いた緑
- 赤: エラー / 削除 / 重大な矛盾に限定
- 通常の案内や未設定説明に赤を使わない

## 実装方針

既存の画面別CSSを一度に削除せず、`ui-unification.css` を最終レイヤーとして読み込み、共通基準へ寄せる。その後、画面別の重複・例外を段階的に削減する。

## 整理対象

- `tmp-*.json` 等の一時検証データ
- 使われていないCSS
- 旧デザイン専用の色指定
- 重複したスタイル定義
- 同一役割なのに画面ごとに異なるUI

保存データ項目・計算ロジック・migrationは、UI整理だけを理由に削除しない。
